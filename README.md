### 💡 서비스 소개 (About SOYO)
> **"무엇을 안심하고 먹고(식약처 영양·DUR 분석), 식사 후 어디를 안전하게 걸을지(TourAPI 배리어프리·Tmap 보행 라우팅)"**

**소요(SOYO)**는 초고령사회 진입에 대응하여 만성질환자(고혈압, 당뇨 등)와 시니어의 건강한 일상을 지원하는 **통합 웰니스 플랫폼**입니다.  
기존의 분절된 관광/식당 정보 탐색을 탈피하여, 공공데이터(식약처 DUR 및 영양DB, 한국관광공사 TourAPI 및 두루누비)를 기반으로 **식이(안심식당 신호등)와 보행(무장애 맞춤 산책 코스)**을 단일 동선으로 연결합니다.

### 🛠️ 기술 스택 (Tech Stack)
* **Frontend**: React 18, Vite, Supabase JS SDK, NAVER Maps API v3, Geolocation API
* **Backend**: Node.js, Express, AWS RDS (PostgreSQL), Supabase Auth, Nodemailer
* **Open Data & Routing**: 식약처 DUR, 식약처 식품영양DB, 한국관광공사 TourAPI, 두루누비, Tmap 보행자 API
